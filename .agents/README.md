# Vendored agent references

These files are development-time reference material. They are not imported, bundled, or executed by GeoHunt at runtime.

The MapLibre skill material was adapted from [maplibre/maplibre-agent-skills](https://github.com/maplibre/maplibre-agent-skills) and is retained under its MIT license. Local edits tailor the guidance to this repository. See [`LICENSE.md`](LICENSE.md) and [`NOTICE`](NOTICE).

Keeping the references in a separate `.agents/` tree makes the provenance boundary explicit: product code lives under `apps/`, `packages/`, `infra/`, and `tests/`.
